The workspace What it does.

Why each part exists

One mistake each.

The public workspace runs 39 small parts. Each one is there to stop one mistake an agent can make. This page lists them by the moment they act.

One session, six moments. Each box is a link to its list.

A hook acts while the agent works: it can warn, or refuse. A check runs at a commit or a push, and fails it. Every part comes with test cases of its own, and the workspace will not load a part whose cases fail.

The names in the last column are the files in the public repository. The workspace page explains the pattern behind them.

1 A session starts

The agent remembers nothing from yesterday. These five tell it what it would otherwise miss.

The mistakeWhat the workspace doesPart
The agent works from yesterday’s copy, so a fix someone merged last night does nothing.It brings its copy up to date first, unless that would move someone’s work.fast_forward
The build on the main branch is broken, and the agent keeps building on top of it.It is told at the start: what failed, since when, and where to look.ci_notice
A page nobody has reviewed in months is trusted as if it were current.It is told which pages are past their review date.stale_pages
The code it is about to change is behind the real project.It is told which pinned repositories are behind.stale_pins
Yesterday’s session stopped halfway, and today’s starts from nothing.It is shown the note the last session left.handoff_loader

2 It edits a file

An edit is the cheapest moment to stop a mistake: nothing is committed yet.

The mistakeWhat the workspace doesPart
Two agents edit the same folder and undo each other’s work.The first keeps the folder. Any other is sent to a copy of its own.lease
An old copy of the code looks current, so the agent fixes the wrong one.Edits to a shelved folder are refused.shelved
The rules for this kind of file sit on a page the agent never opened.It is shown those rules as it starts the edit.rule_pages
One change needs three other files changed too, and the agent stops at one.After the edit, it is shown the other files that kind of change touches.chain_reminder
An agent edits git’s own settings and switches a guard off.Writes to git’s folder and its settings files are refused.git_folder

3 It runs a command

Some commands cannot be taken back. These seven read a command before it runs.

The mistakeWhat the workspace doesPart
“Add everything” sweeps another session’s files into the commit.It is reminded to add files by name. This one only reminds; it never refuses.no_stage_all
A reset or a forced checkout erases work another session has not saved.Those commands are refused while another session holds the folder.no_discard
A push publishes another session’s unfinished commits.That push is refused while the other session is live.push_lease
A force push rewrites the history everyone else builds on.A force push to the main branch, or deleting it, is refused in every form git offers.no_force_push
The owner’s sign-in can merge past a failing build.That merge is refused. The workspace’s own merge command waits for every required check.no_admin_merge
A shell command rewrites git’s settings and changes what every later command does.Those writes are refused from the shell too.git_folder_shell
A small job goes to the most expensive model, or a hard one to the cheapest.A task handed to a helper must name its tier, and runs on that tier’s model.handoff_tier

4 It tries to finish

One part, and the one people notice first.

The mistakeWhat the workspace doesPart
The agent says it is done while the checks it broke still fail.Its first attempt to stop is refused, with the failure. If it stops again, the failure goes in its report.stop_gate

5 It commits

Most parts wait here. A commit is where a wrong page or a leaked secret would become permanent.

The mistakeWhat the workspace doesPart
A commit carries files this session never wrote.The commit may hold only files the session’s edit tools wrote.edit_ledger
A page links to a page that moved, and sends the agent nowhere.Every link must point at a real file and heading.links
A page buries its purpose, or nobody has reviewed it in months.Every page names its kind, opens with its purpose and carries a review date.page_kinds
The index says “the nightly job” means a class that was renamed last week.Every name the index and the contract use must still exist in the code.aliases
The list of files a kind of change touches names a file that moved.Every path in those lists must exist.chains
One agent tool reads its own instruction file, and that file no longer points at the rules.Each tool’s file must name the contract and the rule pages.pointers
The rules every session reads grow until each one pays for text it never uses.That layer has a size ceiling.loaded_size
A rule says a check enforces it, and the check is gone.Every rule is tagged with how it is enforced, and the tag must be true.rules
A page cites line 212, and the next edit moves it.Pages cite a method, class or heading, never a line number.line_cites
A report opens with background and hides its verdict.Plans, decisions and milestone pages state the verdict near the title.in_short
Someone improves a proven procedure and quietly makes it worse.A proven procedure changes only with a new recorded test run that it still wins.eval_record
A page is called proven with nothing behind it.A proven page names its evidence. An unproven one names when it will be tested.proof
The list of reviews drifts from the reviews themselves.The index must match the records, one per page.review_index
A password or token is committed to a public repository.A line that looks like a token or a private key fails the commit.secret_scan
A private name slips into a public file or commit message.Terms on the maintainer’s private list fail the commit.deny_list
Commit messages follow no pattern, so the history is hard to read.Each subject follows the team’s agreed format.commit_subject
A settings change lets the agent read the secrets files.Both agent tools’ settings must still deny it.agent_settings
Two sessions share one browser and collide.Each session gets a browser of its own.browser_isolation
The workspace pins a commit the upstream project never merged.A pin must sit on the upstream’s default branch.pin_on_default

6 It pushes

The last gate before other people and other sessions see the work.

The mistakeWhat the workspace doesPart
A broken hook reaches the main branch and locks out every session that pulls it.Scripts, hooks and CI reach the main branch only through a pull request, tested on three systems.direct_push
An edit to the guidance contradicts another page, and nobody reads it first.Each change to a guidance page names the review that read it.review_trailer
